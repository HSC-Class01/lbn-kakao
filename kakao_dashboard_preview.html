산식 · 해석 원칙

영업이익률 = 영업이익/매출액 ×100 · 순이익률 = 순이익/매출액 ×100 · 부채비율 = 부채/자본 ×100 · 유동비율 = 유동자산/유동부채 ×100 · 자기자본비율 = 자본/자산 ×100. ROA·ROE는 연간만 계산하며 당기 전체 순이익/전기말·당기말 평균 총자산 또는 총자본 ×100입니다(지배주주 ROE 아님). YoY는 전년 동일 보고기간·동일 연결/별도 기준이며 비교 기준이 0 이하인 경우 미산출합니다. 결측·모호한 매칭·분모 0 이하를 0으로 대체하지 않습니다.
